## Introduction

There are so many data jobs posted - where do you even start? This dashboard v2.0 is a quick tool for **job hunters, job transitioners, and job swappers** to narrow their focus. The dashboard is a single-page UI allowing users to gain insight into skills and salaries by job title using a real-world dataset of 2024 data science job posting. I have been following along with #DataNerd Luke Barousse's self-paced learning - Check out [Luke's great tutorials](https://www.youtube.com/@LukeBarousse) on YouTube!!

## Dashboard Overview
This report is a single page that highlights key performance indicators (KPIs) like **Job Count, Skills Per Job, Median Yearly Salary, Median Hourly Salary**. It also provides quick stats for **Skill Popularity** (by job percent or count) and **Median Salaries across different job title** - all driven by quick-click slicers.
